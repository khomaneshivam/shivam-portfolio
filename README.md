# Shivam Khomane — Personal Portfolio

A brutalist dark-editorial personal portfolio website engineered with **React**, **Tailwind CSS**, and **Vite**.

## ✨ Key Features
- **Editorial Brutalist Design**: Dark void canvas (`#08080a`), electric lime neon accents (`#ccff00`), architectural grid lines, SVG film-grain texture, and custom typography (`Anton`, `Instrument Serif`, `JetBrains Mono`, `Inter`).
- **Interactive 3D Hero Canvas**: Constellation particle grid with mouse gravity pull.
- **Projects Showcase**: Interactive accordion with case study modals for full-stack and ML architectures.
- **Work Experience & Academic Timeline**: Evolware Solutions, Eclerx, MCA & BCA degrees at Sinhgad.
- **Categorized Skills Matrix**: Real-time search & filter across MLOps, ML, Backend, and Frontend.
- **Resume Hub**: Direct official PDF resume download with celebration confetti and in-browser interactive PDF viewer modal.
- **Command Palette (`Ctrl + K` / `Cmd + K`)**: Fast navigation with theme accent switcher.
- **Interactive UNIX CLI Terminal (`~`)**: Embedded terminal emulator with full command suite.
- **Tactile Sound Synthesis**: Built-in procedural Web Audio API feedback with mute toggle.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack
- **Frontend**: React 19, Tailwind CSS 3, Vite, Lucide Icons, Canvas-Confetti
- **Typography**: Anton, Instrument Serif, JetBrains Mono, Inter
- **Hosting**: Vercel / Netlify / VPS Ready
